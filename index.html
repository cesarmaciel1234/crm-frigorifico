Programa principal

El dashboard ejecutivo (deudas, remitos, clientes, KPIs) corre con Flask en tu PC o en Render. No es esta pagina web.

En tu PC:

  • pip install -r requirements.txt
  • python run.py
  • http://127.0.0.1:5005
Para el panel completo en iPhone: deploy en Render.com (HTTPS) y Agregar a inicio en Safari.

iPhone — panel completo

Conecta el repo en Render.com. Luego Safari → URL de Render → Compartir → Agregar a inicio.
